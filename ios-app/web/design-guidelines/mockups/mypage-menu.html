마이페이지 — 메뉴형으로 정리

한 페이지에 다 쌓아서 지저분했던 걸, 메인은 짧은 메뉴로 만들고 긴 내용은 각자 페이지로 뺐습니다.

전 (지저분했던 이유)

인사 + 작업현황 카드 + 소모품 5줄 + 한마디 카드 + 고객센터 4줄을 한 화면에 세로로 다 쌓음
→ 스크롤이 길고, 무엇이 중요한지 구분이 안 됨

후 (메뉴형)

메인 = 인사 + 지금 내 차 한 줄 + 메뉴 4묶음. 스크롤 거의 없음
소모품·한마디·고객센터는 각자 페이지로 분리 → 메뉴에서 눌러 들어감

메인 + 상세 페이지

메뉴는 내 차 / 예약 / 고객센터 / 내 정보 네 묶음으로 나눴습니다. 오른쪽 회색 글씨로 중요한 값만 미리 보여줍니다.
